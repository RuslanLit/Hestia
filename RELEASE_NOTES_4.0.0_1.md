# Hestia 4.0.0_1

Release package for Hestia 4.0.0 build 1.

## Included Assets

- `hestia-4.0.0_1-android.apk`: Android APK for direct installation.
- `hestia-4.0.0_1-windows-setup.exe`: Windows per-user installer.
- `hestia-4.0.0_1-windows-portable.zip`: Portable Windows desktop build.
- `hestia-4.0.0_1-web-static.zip`: Static web client bundle.
- `hestia-4.0.0_1-backend.zip`: Backend server archive.
- `hestia-4.0.0_1-landing.zip`: Landing/site archive.
- `4.0.0-checksums.txt`: SHA-256 checksums for release assets.
- `latest.json`: Update manifest for clients and download pages.

## Not Included Yet

Linux, macOS, and iOS release packages are not included in this release.

- Linux AppImage, DEB, and tar.gz packages still need a Linux Flutter SDK and Linux packaging toolchain.
- macOS DMG still needs a macOS host with Xcode.
- iOS distribution still needs Apple Developer Program access, signing certificates, provisioning profiles, and App Store/TestFlight or another Apple-supported distribution flow.
