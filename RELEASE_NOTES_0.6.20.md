# Hestia 0.6.20

Android-first public release checkpoint.

## Available

- Android APK builds for direct GitHub Release download.
- ABI-specific APK choices:
  - `arm64-v8a` for most modern Android phones and tablets.
  - `armeabi-v7a` for older 32-bit Android devices.
  - `x86_64` for emulators and uncommon Intel or ChromeOS-style Android devices.
- Android incoming call wake-up and notification handling from the stable checkpoint.
- Message notifications and Android background reachability behavior from the stable checkpoint.

## Planned

- Web app public release.
- Windows, Linux, macOS, and iOS public builds.

## Notes

- APK installation is manual. Android may ask users to allow installation from unknown sources.
- Download APKs only from the official Hestia GitHub Release.
